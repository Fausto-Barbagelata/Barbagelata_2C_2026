Descripción detallada

Driver para el acelerometro digital de 3 ejes ADXL345 (Analog Devices) sobre interfaz SPI de 4 hilos, usando la capa HAL spi_mcu.c/h.

Pensado para un monitor ambulatorio de flujo glotico (uso continuo de varios dias con bateria). Se priorizan lecturas en rafaga (burst), uso de FIFO y modos de baja potencia para minimizar transacciones SPI y consumo de energia.

Referencia: ADXL345 Data Sheet Rev. D (Analog Devices).
